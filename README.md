# 言奏 Katarune

> 让语言拥有记忆、声音与形体。

言奏（Katarune）是一个面向数字角色与桌面陪伴场景的开放式 AI 应用。它以对话为主要交互入口，将模型、记忆、工具、语音和数字形体组合为可持续存在的角色体验。

项目已经完成 P1 技术验证基线。P2 的可信模型流、工具调用与可恢复会话已经贯通，当前剩余项是接入首个 TTS Provider；角色与资产管理、多会话等 P3 工作已同步展开，附件、长期记忆、语音和数字形体仍按独立边界继续验证。
