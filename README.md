# 言奏 Katarune

> 让语言拥有记忆、声音与形体。

言奏（Katarune）是一个面向数字角色与桌面陪伴场景的开放式 AI 应用。它以对话为主要交互入口，将模型、记忆、工具、语音和数字形体组合为可持续存在的角色体验。

项目已经完成 P1 技术验证基线，正在进入 P2 最小垂直闭环：先接通可信模型流、工具调用与可恢复会话，再继续扩展角色、语音、记忆和数字形体能力。
