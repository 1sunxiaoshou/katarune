# 路线图

本页维护当前进度、待验收事项和后续方向，不绑定日期。运行机制见架构文档，操作见[工程规范](../04-开发/工程规范.md)，选择理由见[决策记录](../01-决策/决策记录.md)；逐轮开发与测试过程保留在 Git 提交中。

## 当前阶段

[Windows Alpha v0.1.0](https://github.com/1sunxiaoshou/katarune/releases/tag/v0.1.0) 已发布。这一阶段的重点是通过实际使用验证日常陪伴体验，体验版本以下列条件为准：

- 首次安装后能完成模型配置与第一次交谈。
- 当前角色的语音、表情、动作和字幕协调一致。
- 重启后角色、会话与记忆得以延续。
- 配置或服务失败时，使用者能理解原因并恢复。

自动化覆盖可重复的路径；真实观感与一周使用反馈单独记录。

### 海岛方向

2026-11-13 使用者确认：以「异世界海岸」作为场景基础，布局与后续互动围绕自己的海岛设计，原神作为建筑、植被、摆件与动画的美术来源；停止稻妻整景替换，已整理的尘歌壶素材保留供选用。

当前海岸仍是装饰背景：角色手脚可以推动椰子、激起水面涟漪，漂浮木有浮力，但还没有阻挡角色移动的控制器，也没有自由移动、场景互动或 AI 对世界的感知。

- **直播媒体偶发中断**：Unity 升级后的首轮直播验证出现过一次启动失败和一次媒体退出；海岸背景首次与沉浸 Player 检查并行运行时出现过一次媒体传输中断。之后的串行回归均通过，但根因尚未定位，不视为已修复。

## 长期方向

数字生命的活动范围可以延伸到日常消息、共同游戏、虚拟世界和未来的实体躯体。以下均为探索方向，尚无确定的实现方案或交付承诺：

- 与人共同活动，在虚拟世界中移动、玩耍和探索。
- 通过实体躯体获得观察、移动与物理世界交互能力。
- 根据真实需求扩展 MCP，并决定 ACP／A2A、外部平台及成熟的感知行动能力。
