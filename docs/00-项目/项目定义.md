# 项目定义

## 愿景

**Katarune，新一代的数字伙伴~**

Katarune 致力于创造能与人共同生活、感知和探索世界的数字生命。TA 可以在电脑中与人互发消息、一起游戏，在虚拟世界中活动；未来也可以拥有实体躯体，观察、移动和探索物理世界。

这是长期愿景。当前从对话、角色记忆、语音和数字形体建立体验基线；游戏互动、虚拟世界和实体躯体尚未实现，具体方案与推进顺序留待后续任务确定。

## 当前范围

- 模型配置、流式对话、多会话与本地恢复。
- 角色设定、声音、角色包与资产管理。
- 角色独立的长期记忆。
- 语音输入、回复与插话。
- 数字形体的表情、动作、口型、字幕与桌面交互。

已有能力和剩余工作见[路线图](../03-规划/路线图.md)，本页不重复维护进度。

## 实现原则

现阶段以 Web 技术构建产品 Harness，复用成熟模型、Agent Runtime、聊天组件与开放协议。自研投入集中在角色、记忆策略、语音协调、数字形体、感知行动和用户控制。

当前技术选择服务于这一阶段，不限制长期愿景。普通功能任务不扩展成通用文件、终端、编码代理或跨 Harness 平台，也不为未知需求预建兼容层。

用户控制供应商、数据与权限。敏感能力留在可信进程；不迁移旧项目的用户数据、会话或记忆。

## 名称

产品、窗口与安装包统一使用 **Katarune**，仓库标识为 `katarune`。名称结合了讲述（`kataru`）、符文（`rune`）与声音（`tune`）的意象。公开发布前仍需完成名称可用性及许可证确认。
