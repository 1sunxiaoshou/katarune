# 桌面交互设计

> 当前规则按 D-063 及其后续修订实施：Unity 在选定屏幕使用全屏透明窗口，Electron 提供胶囊与面板。移动和缩放只改变 Unity 内的角色构图。

## 窗口与生命周期

| 窗口 | 职责 | 输入 |
| --- | --- | --- |
| Unity 角色 | 模型、动作、音频、口型、字幕时间轴及气泡 | 正常整窗穿透；调整时仅角色操作区接收输入 |
| Electron 胶囊 | 聊天、麦克风、角色调整、更多 | 显示不抢焦点，用户点击正常聚焦，自由拖动与跨屏 |
| Electron 面板 | 更多与操作说明共用窗口 | 整窗接收点击，用户打开后可用键盘 |

Electron 主进程统一管理显示器、DIP 布局、层级和偏好；仅 Unity 写入自己的 HWND。所有桌宠窗口使用工具窗口行为，不增加任务栏与 Alt+Tab 入口，显示和移动不主动抢焦点；用户打开面板时允许取得焦点。层级为面板、胶囊、角色，均置于普通应用之上。原生模式变化、显示及恢复时重新应用窗口策略。Unity 低频检查真实窗口样式，不逐帧抢前台。主进程将可见胶囊和面板的实际物理矩形同步给 Unity，作为输入排除区；即使 Unity 短暂升到前方，这些位置也保持穿透，让下面的控件能接收点击。

桌宠启动时创建窗口组；Unity 启动失败由胶囊提供重试，并在面板显示原因。停止后销毁窗口、注销快捷键、取消布局请求及保存计时器。聊天窗口使用明确引用，关闭仍退出应用；最小化或查看设置不影响桌宠。轻量桌宠 renderer 只装载显示组件，不创建聊天 Runtime、麦克风采集、ASR 或音频播放器；IPC 只向指定窗口发送。

## 会话与语音

桌宠按钮只负责开关和失败重试。开启后自动跟随当前角色和会话，保留 Unity 进程及模型；关闭后浏览会话不自动启动。旧文本生成可继续，旧会话的音频、字幕、口型和动作停止，切回不补播。复用 `startAvatar(binding)`、绑定代次与 `session-reset` 回执；5 秒无确认或断线进入错误，等待手动重试。

首次开启桌宠继续使用既有自动开麦规则，切换会话保留期望开关。缺少语音配置不关闭模型。胶囊麦克风显示关闭、待听、收音声波、准备/识别/等待和错误状态，收起后仍保留麦克风。聊天中的麦克风只做一次听写。语音采集和自动发送继续使用聊天 renderer 中唯一的语音生命周期。

角色说话期间持续收音；疑似插话先暂停播放及时间轴，空识别恢复，最终文字确认后打断旧播放。完整规则继续见 D-061。字幕由 Unity 的实际 AudioSource 游标或既有无声阅读时间轴决定，并在角色窗口内直接绘制；不再回报独立字幕显示事件。Electron 不切句、不估时、不启动播放时钟；空白隐藏，打断、切换、停止和异常立即清空。字幕固定在角色所在屏幕底部居中，字号按屏幕 DPI 保持可读，不参与角色缩放或位置调整。

## 默认布局与记忆

Unity 窗口覆盖角色选定显示器的完整物理屏幕。主进程仅在首次布局、面板切屏、分辨率改变或断屏恢复时向 Unity 发送目标屏幕矩形。日常中键拖动和滚轮缩放只改变 Unity 相机的投影中心与 FOV，不移动或缩放 HWND。左键继续旋转角色。角色操作区由静态模型投影范围加宽松边距生成；区外背景点击穿透，拖动开始后保持接收至松手。胶囊和面板的物理矩形始终排除在 Unity 输入区之外。

首次位置为屏幕右侧，角色高度约占屏幕 65%。调整模式允许继续放大到局部特写，投影只受相机有效 FOV 边界限制。中键平移允许投影中心越过屏幕边缘，只要求角色投影至少保留约 64 个物理像素的可抓取范围；小于该范围的投影保持完整可见。角色位置、屏幕占高、朝向和目标显示器以归一化数据保存在 `userData/avatar-desktop-layout.json`。切换屏幕时沿用同一构图数据并在目标屏幕重算投影与平移边界；断屏回退主屏。旧小窗口几何偏好不迁移，以免把窗口位置误当作角色位置。胶囊使用独立的窗口位置偏好，系统原生拖动可跨屏。首次和重置时位于屏幕右下方；角色切屏不移动胶囊。

完整布局请求含目标屏幕矩形和角色构图；输入模式请求不写窗口矩形，也不重置构图。Unity 回执包含实际窗口矩形和角色构图；只有用户操作后的构图回报才保存为偏好。胶囊、面板保持在 Unity 上层，Unity 窗口策略恢复后主进程重新排序。

字幕由 Unity 播放时间轴驱动，固定在角色所在屏幕底部居中；切屏时随 Unity 窗口切换。底部留白按当前屏幕高度计算，低分辨率保留最小间距；字号按 DPI 保持可读，不随角色缩放。字幕本身不接受拖动，也不另存位置。

## 紧凑控制面板

更多与操作说明共用最大 320×410 DIP 窗口，切换内容不改变尺寸，仅在胶囊周围或屏幕可用空间不足时缩小；内容过多在内部滚动。面板在胶囊可见轮廓旁以 8 DIP 间隔展开，优先置于下方并对齐可见右边缘；空间不足时改为上方或左边缘对齐。复用主程序主题、Lucide、Tabler 表情图标、按钮、开关、选择器与胶囊单选组件，不另设分类标题、分组卡片或五个 Tab。胶囊和面板均无边框，使用柔和阴影。

- 模型：单行名称与打开/重载图标；系统文件选择由主进程处理，失败保留原模型。
- 表情：按实际能力生成图标在左、短名称在右的选择项，三列排列；六项时为两行。当前表情依据 Unity 回报显示主题色选中块，悬停未选项显示灰底；选中块与视线、描边单选共用设置页的 200 毫秒指示块过渡，减少动态效果时关闭过渡。
- 动作：统一下拉；选择即执行，结束显示“无”，选择“无”停止动作。
- 角色屏幕：下拉选择当前连接的显示器；只在切换时移动 Unity 全屏窗口。
- 视线：已有单选组件“无／鼠标”。
- 描边：以“默认／柔和”单选呈现，首次使用选默认；“默认”恢复模型自带的轮廓参数，并不保证完全没有线条。选择状态以 Unity 回报为准，用户已保存的选择继续生效。
- 面板从上到下排列为表情、动作、视线追踪、描边、角色屏幕、布局。控制行右侧的下拉、二选一与重置按钮统一为 152 DIP 的目标宽度，窄屏可收缩；下拉列表仍按内容宽度显示，长名称受面板宽度限制。
- 布局：左侧写“布局”，右侧使用“重置”按钮，按钮的可访问名称为“重置布局”。
- 四向箭头直接切换位置调整模式，不打开额外面板；开启时保持选中高亮，退出恢复普通样式，可访问名称随状态变化，无 Tooltip。左键旋转、中键移动、滚轮缩放。重置布局在更多面板中。
- 顶部键盘图标进入同一面板的说明视图，并在原位置变为返回图标；左侧操作、右侧按键帽。鼠标操作用图标表示，保留可访问名称。

F1 只在桌宠开启期间注册，隐藏/显示胶囊和面板；Esc 关闭面板或退出调整。调整模式中临时注册 Esc，退出立即注销。通用 Tab、Shift+Tab、Enter 沿用组件键盘行为，不另行拦截或列入说明。桌宠 UI 无 Tooltip，图标保留可访问名称。

面板失焦收起；焦点转到胶囊时交由被点击的按钮处理，避免失焦与按钮切换互相抵消。收起面板与退出调整分别处理，面板失焦及拖动胶囊均不取消调整；Esc 或再次点击四向箭头退出并恢复穿透。内部下拉在面板内展开，不改变原生输入策略；系统文件对话框期间不因失焦关闭。拖动胶囊先收起面板，下次按胶囊当前屏幕定位。

胶囊允许用户点击聚焦，启动仍使用不激活窗口的显示方式；按钮显式排除原生拖动区。面板处理异步失焦时核对当前可见性与焦点，忽略隐藏或重新聚焦后的迟到事件。调整模式下鼠标在稳定的角色操作区外继续穿透；左键或中键拖动开始后保持接收输入直到松手。普通面板开关不重设 Unity 窗口布局，只同步面板输入排除区；置顶恢复不反复取消置顶。面板使用 100ms 淡入位移、12 DIP 圆角与柔和阴影，保持紧凑排列。

面板保持同一 DOM，不通过更换 key 重播动画。主进程按 `closed → preparing → open` 管理显示：隐藏时准备内容和透明起始状态，renderer 等两次 `requestAnimationFrame` 后发送带本次 revision 的 `panel-ready`；主进程仅接受仍在准备中的当前回执，再显示窗口并进入 open，播放一次出现动画。普通状态更新与更多/说明切换不重新播放。关闭、拖动胶囊或停止桌宠取消准备，迟到回执不恢复窗口；隐藏时同时关闭下拉 Portal，避免重开显示旧弹层。

已移除卸载模型、界面大小、恢复默认行为入口，以及旧 Unity HUD 控件、样式、字体图标资源、专用测试、UI 缩放和偏好读写。内部模型资源释放、会话表演重置与失败回滚继续保留。

## 验证边界

本轮以 Unity 命中范围测试、Electron 类型和 UI 检查及 Windows Player 截图验证代码路径。自动检查和录屏不能替代用户对胶囊/面板点击、原生拖动、跨 DPI 裁切及连续滚轮缩放的实际体验验收；这些现象须分别确认，不能由其中一项通过推定其余已解决。

电脑工具能启动、停止和检查聊天入口，但不枚举 Unity 与 Electron 工具窗口。未能通过该工具完成工具窗口的真实点击、拖动、下拉、跨屏、拔屏与音画同步体验验收；原生样式读取和协议诊断只能证明相应状态，不能替代这些操作。最终结果以实施回复及检查输出为准。

未来世界态、自动重连、安装包内置 Unity、复杂外放回声与流式文本输入仍是独立事项。本次不增加后台驻留、角色模型映射、第二个 Unity 进程或自定义快捷键系统。
