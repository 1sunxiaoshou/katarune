# 桌面交互设计

> 当前规则按 D-063 实施：一个 Unity 角色小窗口，三个 Electron 桌宠窗口。原全屏 Unity HUD 与位置偏好路径已移除。构建与自动检查不代表多屏切换、外放和真实同步体验已验收。

## 窗口与生命周期

| 窗口 | 职责 | 输入 |
| --- | --- | --- |
| Unity 角色 | 模型、动作、音频、口型、字幕时间轴 | 正常整窗穿透；调整时接收输入 |
| Electron 字幕 | 显示 Unity 当前片段，用户浅色、角色深色 | 正常穿透且不取焦点；调整时可拖动 |
| Electron 胶囊 | 聊天、麦克风、角色调整、更多 | 显示不抢焦点，用户点击正常聚焦，自由拖动与跨屏 |
| Electron 面板 | 更多与操作说明共用窗口 | 整窗接收点击，用户打开后可用键盘 |

Electron 主进程统一管理显示器、DIP 布局、层级和偏好；仅 Unity 写入自己的 HWND。所有桌宠窗口使用工具窗口行为，不增加任务栏与 Alt+Tab 入口，显示和移动不主动抢焦点；用户打开面板时允许取得焦点。层级为面板、胶囊、字幕、角色，均置于普通应用之上。原生模式变化、显示及恢复时重新应用窗口策略。Unity 低频检查真实窗口样式，不逐帧抢前台。

桌宠启动时创建窗口组；Unity 启动失败由胶囊提供重试，并在面板显示原因。停止后销毁窗口、注销快捷键、取消布局请求及保存计时器。聊天窗口使用明确引用，关闭仍退出应用；最小化或查看设置不影响桌宠。轻量桌宠 renderer 只装载显示组件，不创建聊天 Runtime、麦克风采集、ASR 或音频播放器；IPC 只向指定窗口发送。

## 会话与语音

桌宠按钮只负责开关和失败重试。开启后自动跟随当前角色和会话，保留 Unity 进程及模型；关闭后浏览会话不自动启动。旧文本生成可继续，旧会话的音频、字幕、口型和动作停止，切回不补播。复用 `startAvatar(binding)`、绑定代次与 `session-reset` 回执；5 秒无确认或断线进入错误，等待手动重试。

首次开启桌宠继续使用既有自动开麦规则，切换会话保留期望开关。缺少语音配置不关闭模型。胶囊麦克风显示关闭、待听、收音声波、准备/识别/等待和错误状态，收起后仍保留麦克风。聊天中的麦克风只做一次听写。语音采集和自动发送继续使用聊天 renderer 中唯一的语音生命周期。

角色说话期间持续收音；疑似插话先暂停播放及时间轴，空识别恢复，最终文字确认后打断旧播放。完整规则继续见 D-061。字幕由 Unity 的实际 AudioSource 游标或既有无声阅读时间轴决定，仅在片段变化时回报文字、说话方、绑定代次和运行 ID。Electron 不切句、不估时、不启动播放时钟；空白隐藏，打断、切换、停止和异常立即清空。

## 默认布局与记忆

参考视图为 1920×1080，旧相机缩放 70%、朝向 0°、俯仰 4°。Unity 从旧投影计算静态角色范围，再留出稳定动作边距；70% 不等于角色占屏高度。主进程等待模型正式构图数据后换算窗口大小，按可用区域高度缩放并受宽度约束。默认将角色窗口放在工作区右下角，距右边 16 DIP，并在下方为胶囊预留空间；高度不足时先缩小角色窗口。窗口不会逐帧追随发丝或动作变化。移动改变原生窗口坐标，缩放改变窗口尺寸并保持构图。

模型加载构图时固定相机距离、构图和 FOV；运行中的 Screen 尺寸变化只更新投影宽高比，不重新拟合角色。滚轮缩放使用双精度高度、固定宽高比与稳定中心计算目标矩形，直到写入 Win32 才取整；后续缩放不从上一次取整值累计。系统实际改变原生窗口尺寸时重新校准缩放基准，避免旧目标与实际尺寸分离。窗口几何与相机构图各自只有一条更新路径。滚轮输入直接更新原生窗口，位置与缩放沿用已有状态回报，不保留待处理矩形或帧末协程。首次布局、重置与输入模式请求保留已有路径；模式请求不写几何。

角色取消位置与屏幕边界限制，可部分越界或直接跨屏。胶囊和字幕由系统原生拖动，不拦截移动、不在松手后拉回。屏幕归属以实际窗口矩形为准，删除三个屏幕下拉、对应 IPC 命令及 renderer 显示器状态。字幕默认跟随角色实际所在屏幕，手动拖到其他屏幕后独立记忆；重置布局恢复默认跟随。调整模式下空字幕显示位置预览。

默认胶囊水平居中放在角色窗口下方，两窗间隔 16 DIP，胶囊底部距工作区底边 16 DIP；两窗不重叠，并在工作区内约束胶囊位置。首次构图就绪和重置时应用，用户拖开后独立记忆，不因角色切屏而追随。已有保存布局继续保留，可通过重置布局应用新默认值。

胶囊通过左侧拖动柄使用 Electron 原生窗口拖动，主进程只监听拖动开始以收起面板，不通过 renderer 逐次鼠标 IPC 移动。原生宿主保持 240×64 DIP，胶囊本体在 220×44 和 100×44 之间以 220ms 过渡，边缘留出柔和阴影。`setShape()` 同时裁切绘制和鼠标输入，区域由胶囊当前 DIP 尺寸派生，收起后隐藏部分不拦截点击。renderer 通过 `matchMedia(resolution)` 监听实际生效的 DPR 变化，复用原有尺寸上报重建同一 DIP 轮廓；`ResizeObserver` 继续负责收展尺寸。已删除无效的 `WM_DPICHANGED + setImmediate` 补偿，该刷新不设置窗口位置或尺寸。已删除拖动跨屏的显示器探测、位置/尺寸补偿和松手落屏判断。减少动态效果开启时取消动画。

胶囊与字幕拖动期间不调用 preventDefault、setBounds 或 setPosition，松手后读取实际窗口矩形保存位置；字幕拖动期间暂停自动定位。胶囊不在 resize 回调中强制写尺寸，DPI 适配交由系统与 Electron。Unity 角色仍通过每帧原生鼠标坐标移动窗口，已删除工作区协议与 Constrain 限制；这条路径并非系统标题栏拖动，其流畅度需单独实测。

主进程使用一份 `userData/avatar-desktop-layout.json` 保存角色和胶囊的显示器标识、归一化位置、角色相对尺寸与朝向、字幕可选显示器与偏移、描边与视线偏好。操作后防抖保存，正常退出时落盘，不周期性快照、不迁移数据库。Unity 不读写旧位置 PlayerPrefs。坐标只在 Unity 窗口协议边界转换为物理像素。

Unity 最新回报的实际窗口矩形是运行时位置及屏幕归属的事实源；程序回执更新实际位置，但不反向改写归一化保存偏好。所有窗口回报携带当前布局请求 ID，仅接受最新布局的消息；只有明确的手动移动、缩放、旋转（含惯性）才反算并保存偏好，避免 DPI 与整数像素往返累积误差。

进入和退出调整仅发送输入模式，不携带位置、尺寸和朝向；通过显式 applyGeometry 标识区分完整布局，Unity 保留现场矩形与姿态，避免副屏物理像素与 DIP 往返取整导致累积偏移。模式请求同样返回完成回执，不能依赖反序列化后矩形是否为 null 判断请求类型。

分辨率/DPI 改变时按原显示器重算；启动或运行中断屏都只把受影响窗口恢复到主屏默认位置。更多面板中的“重置布局”将角色、字幕和胶囊恢复到角色当前屏幕上的默认位置，字幕恢复跟随角色，并保存，不弹确认框。

## 紧凑控制面板

更多与操作说明共用 320×410 DIP 窗口，切换内容不改变尺寸，仅在屏幕可用空间不足时缩小；内容过多在内部滚动。面板依胶囊所在屏幕向可用空间展开。复用主程序主题、Lucide、按钮、开关、选择器与胶囊单选组件，不另设分类标题、分组卡片或五个 Tab。胶囊和面板均无边框，使用柔和阴影。

- 模型：单行名称与打开/重载图标；系统文件选择由主进程处理，失败保留原模型。
- 表情：按实际能力生成短名称选择，整体居中；超过六项使用两列排列。
- 动作：统一下拉；选择即执行，结束显示“无”，选择“无”停止动作。
- 视线：已有单选组件“无／鼠标”。
- 描边：开关，以 Unity 回报为准。
- 下拉触发器和列表按内容宽度显示，长名称受面板宽度限制，不铺满整行或沿用聊天模型选择器的固定宽度。
- 四向箭头直接切换位置调整模式，不打开额外面板；开启时保持选中高亮，退出恢复普通样式，可访问名称随状态变化，无 Tooltip。左键旋转、中键移动、滚轮缩放。重置布局在更多面板中。
- 顶部键盘图标进入同一面板的说明视图，并在原位置变为返回图标；左侧操作、右侧按键帽。鼠标操作用图标表示，保留可访问名称。

F1 只在桌宠开启期间注册，隐藏/显示胶囊和面板；Esc 关闭面板或退出调整。调整模式中临时注册 Esc，退出立即注销。通用 Tab、Shift+Tab、Enter 沿用组件键盘行为，不另行拦截或列入说明。桌宠 UI 无 Tooltip，图标保留可访问名称。

面板失焦收起；焦点转到胶囊时交由被点击的按钮处理，避免失焦与按钮切换互相抵消。收起面板与退出调整分别处理，面板失焦及拖动胶囊均不取消调整；Esc 或再次点击四向箭头退出并恢复穿透。内部下拉在面板内展开，不改变原生输入策略；系统文件对话框期间不因失焦关闭。拖动胶囊先收起面板，下次按胶囊当前屏幕定位。

胶囊允许用户点击聚焦，启动仍使用不激活窗口的显示方式；按钮显式排除原生拖动区。面板处理异步失焦时核对当前可见性与焦点，忽略隐藏或重新聚焦后的迟到事件。字幕仅在进入或退出调整时改变焦点与穿透策略，并保持隐藏任务栏入口，不在每次状态回报中重写原生输入策略。普通面板开关不发送 Unity 窗口布局，置顶恢复不反复取消置顶；面板使用 100ms 淡入位移、12 DIP 圆角与柔和阴影，保持紧凑排列。

面板保持同一 DOM，不通过更换 key 重播动画。主进程按 `closed → preparing → open` 管理显示：隐藏时准备内容和透明起始状态，renderer 等两次 `requestAnimationFrame` 后发送带本次 revision 的 `panel-ready`；主进程仅接受仍在准备中的当前回执，再显示窗口并进入 open，播放一次出现动画。普通状态更新与更多/说明切换不重新播放。关闭、拖动胶囊或停止桌宠取消准备，迟到回执不恢复窗口；隐藏时同时关闭下拉 Portal，避免重开显示旧弹层。

已移除卸载模型、界面大小、恢复默认行为入口，以及旧 Unity HUD 控件、样式、字体图标资源、专用测试、UI 缩放和偏好读写。内部模型资源释放、会话表演重置与失败回滚继续保留。

## 验证边界

本轮不新增测试文件或测试用例，仅调整/删除旧界面失效断言，运行现有相关检查及 Electron、Unity Player 构建。构建和既有测试不能代替用户对原生窗口拖动、跨 DPI 胶囊裁切、面板单次出现动画及连续滚轮缩放的视觉验收；这些现象须分别确认，不能由其中一项通过推定其余已解决。

电脑工具能启动、停止和检查聊天入口，但不枚举 Unity 与 Electron 工具窗口。未能通过该工具完成工具窗口的真实点击、拖动、下拉、跨屏、拔屏与音画同步体验验收；原生样式读取和协议诊断只能证明相应状态，不能替代这些操作。最终结果以实施回复及检查输出为准。

未来全屏世界态、自动重连、安装包内置 Unity、复杂外放回声与流式文本输入仍是独立事项。本次不增加后台驻留、角色模型映射、第二个 Unity 进程或自定义快捷键系统。
